# English with Betül Hoca

Kocatepe Ortaokulu İngilizce ödev ve etkinlik platformu (5–8. sınıflar).

- `index.html` — öğrenci girişi (sınıf + şube + okul no + 4 haneli şifre), ödevler, geri bildirimler, rozetler
- `ogretmen.html` — öğretmen paneli: ödev hazırlama, sonuçlar, haftalık geri bildirim, not defteri, öğrenci listesi, ayarlar
- `firestore.rules` — Firebase güvenlik kuralları
- Deneme modu: adresin sonuna `?demo=1` ekleyin
